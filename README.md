# David Baum | softcoding for you

The portfolio of David Baum, Research Engineer and Software Developer, who works independently under the name **softcoding for you**.

🌐 **Live Site**: [softcodingforyou.github.io](https://softcodingforyou.github.io)

## About

David is a Research Engineer at InteraXon Inc. (Muse) with a PhD in Neurophysiology, and was previously co-founder and CTO of Helment. This site lists his work: research tools, client projects and small apps.

## Features

### 🎨 Design
- **softcoding for you identity**: green palette (Cream, Paper, Mint, Forest, Ink), the Recursive typeface, and Bommel, the googly-eyed mascot, used sparingly
- **Light and dark themes** that follow the OS until the visitor picks one, with no flash on load
- **Fully responsive** layout for desktop, tablet and mobile
- **Accessible**: semantic HTML, keyboard support, reduced-motion support

### 📱 Content Sections
- **Hero**: Professional introduction. The portrait coin flips to Bommel, the mascot, on hover, tap or keyboard
- **About**: Background and a timeline of roles and education
- **Projects**: Four flagship projects (EazzZyLearn, KA'A, Securicata, NeuriGUI) and smaller projects
- **Additional Experience**: Client work (Acupuntura Tung) and community leadership (astronomy club)
- **Skills & Technologies**: Core and supporting technologies, specializations, languages
- **Footer**: GitHub and email, plus the "made by softcoding for you" badge
- **404 page**: shows the address that was tried, suggests the section or project the visitor probably meant, speaks their language (EN/DE/FR/ES), and Bommel looks around for the missing page

## Development

### Local Development
1. Clone the repository
2. Run `python -m http.server 8000` and open http://localhost:8000
3. No build process required. This is a pure static site

### GitHub Pages Deployment
- Automatically deployed via GitHub Pages
- Serves from the `main` branch
- `404.html` is served automatically for unknown paths
- Custom domain can be configured via CNAME

## Browser Support

- **Modern Browsers**: Chrome, Firefox, Safari, Edge (latest versions)
- **Mobile Browsers**: iOS Safari, Chrome Mobile, Samsung Internet
- **Features**: CSS Grid, Flexbox, Custom Properties, ES6+ JavaScript, WebP
